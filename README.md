# SAP ABAP exercises

A source collection of small ABAP learning exercises. The numbered reports in ABAP101 explore language and report-programming concepts; the repository is not a packaged SAP product or a production OMS implementation.

## Contents

- [ABAP101](ABAP101): numbered ABAP report exercises.
- [Hello World.abap](Hello%20World.abap): a standalone introductory example.
- [Exercise guide](docs/EXERCISES.md): how to explore the sources safely.

## Quick start

1. Download or clone the repository.
2. Use an SAP training, sandbox, or development system to which you are authorized.
3. Open an exercise in ABAP Development Tools for Eclipse or in the SAP GUI ABAP workbench.
4. Review the report name, dependencies, and exercise comments; then create or adapt an appropriate development object in your own namespace before activating it.

The samples are meant for learning. Do not copy them directly into a production system or transport them without the normal code review, authorization, and transport process.

## Platform and technologies

- ABAP report programs.
- SAP development environment: ABAP Development Tools (ADT) or SAP GUI workbench.
- No executable download or local build pipeline is provided; execution happens in an SAP ABAP system.
